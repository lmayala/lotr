# Ring Quest

Welcome to **Ring Quest**.

This interactive lab teaches the fundamentals of Docker through a Middle-earth adventure.

You will work inside a Docker-in-Docker environment and complete practical challenges while following Frodo and the hobbits from the Shire toward Rivendell.

### What you will practice
- Understanding images vs containers
- Listing and inspecting containers
- Using `docker exec`
- Running containers from images
- Writing basic Dockerfiles

### How to start
The environment is already prepared.  
Follow the on-screen instructions and use the `helpme` command when you need guidance.

Enjoy the journey.
One does not simply learn Docker... but you will.
